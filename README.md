# CCS Website

A modern, responsive website for the College of Computer Studies, built with Next.js and React.

## Features

- Responsive navigation bar with desktop and mobile support
- Navigation links automatically hide to avoid overlapping with the site title
- Mobile menu button appears when navigation links are hidden or on small screens
- Clean, modern UI using Tailwind CSS

## Project Structure

```
ccs-website/
  app/                # Next.js app directory
  components/         # Reusable React components
  lib/                # Utility functions
  public/             # Static assets
  ...
```

## Getting Started

1. **Install dependencies:**
   ```sh
   npm install
   ```
2. **Run the development server:**
   ```sh
   npm run dev
   ```
3. **Open your browser:**
   Visit [http://localhost:3000](http://localhost:3000)

## Customization

- Edit navigation links in `components/navigation.tsx`.
- Update styles using Tailwind CSS classes in the component files.
